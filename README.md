# Book Store MERN Project

This is a **Book Store** application built using the MERN stack (**MongoDB**, **Express.js**, **React**, and **Node.js**). The project allows users to perform CRUD operations on books, view details, and manage the bookstore effectively.

## Features

### Backend (Node.js + Express.js)
- **MongoDB Integration**: Added MongoDB and Mongoose for database management.
- **CRUD Operations**:
  - Create, read, update, and delete books using Mongoose models.
  - Retrieve one or all books via API endpoints.
- **CORS Policy**: Configured CORS to allow cross-origin requests.
- **Express Router**: Refactored routes for better modularity.

### Frontend (React + Vite)
- **Single Page Application (SPA)**: Built with React and React Router DOM for smooth navigation.
- **Book Management**:
  - View all books as a list of cards.
  - Add, edit, and delete books using modals and forms.
  - View detailed information about a specific book.
- **Improved UX**: Added beautiful alerts and modals for better user experience.
- **Responsive Design**: Styled with Tailwind CSS for a modern, responsive UI.
